Chief of Staff VPS

A personal assistant integration operated by Danil Retunsky for his own account. It helps find and read Google Drive files for user-requested Chief of Staff work and stores selected new files in a designated private Drive folder.

Google Drive access uses a separate OAuth connection. The integration requests read access to Drive files and write access to files created through the application. Existing files are not given broad write permissions by this scope selection.

Relevant retrieved content may be supplied to the Hermes assistant and its configured AI provider to answer the owner’s requests. The public website contains only app information.
